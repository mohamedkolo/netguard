# ClinicFlow — منصة إدارة العيادات

نظام إدارة عيادات بالعربي، بيشتغل في المتصفح على طول من غير سيرفر ولا تنصيب ولا اشتراك.

## اللي بيعمله

| الصفحة | اللي فيها |
|---|---|
| **لوحة التحكم** | مواعيد النهاردة، عدد المرضى، المحصّل والمستحقات، رسم بياني لآخر ٧ أيام |
| **المواعيد** | حجز وتعديل المواعيد، تنقّل بين الأيام، تغيير الحالة، طباعة جدول اليوم |
| **المرضى** | ملف كامل لكل مريض: بياناته، مواعيده، سجله الطبي، مستحقاته — وطباعة الملف |
| **السجلات الطبية** | الأعراض والتشخيص والروشتة لكل زيارة + **طباعة روشتة** جاهزة بتوقيع الطبيب |
| **الأطباء** | التخصصات وأسعار الكشف ومواعيد العمل |
| **الفواتير** | فاتورة ببنود متعددة، خصم، دفع جزئي، وطباعة الفاتورة |
| **التقارير** | ملخص أي فترة: المواعيد حسب الطبيب، أكتر التشخيصات، الملخص المالي |
| **الإعدادات** | بيانات العيادة، الخدمات والأسعار، النسخ الاحتياطية |

كمان: وضع ليلي، تصميم شغال على الموبايل، ومنع تلقائي لحجز نفس الطبيب في نفس التوقيت مرتين.

## التشغيل

الملفات دي HTML و CSS و JavaScript عادية — مفيش build ولا `npm install`.

**محليًا:** لازم تشغّلها من سيرفر بسيط (مش بفتح `index.html` مباشرة، عشان المتصفح بيمنع الـ modules من ملفات محلية):

```bash
cd clinicflow
python3 -m http.server 8000
# افتح http://localhost:8000
```

**على الإنترنت مجانًا (GitHub Pages):** Settings → Pages → Deploy from a branch → `main` + `/ (root)` → Save.

## البيانات — اقرا ده كويس

البيانات محفوظة في **IndexedDB** جوه متصفح الجهاز اللي شغال عليه، ومش بتروح لأي سيرفر. يعني:

- ✅ سريعة، مجانية، وبتشتغل من غير نت
- ✅ مفيش بيانات مرضى بتخرج بره الجهاز
- ⚠️ **البيانات على الجهاز ده بس** — مش هتلاقيها على جهاز تاني أو متصفح تاني
- ⚠️ لو مسحت بيانات المتصفح، البيانات بتتمسح معاها

**علشان كده:** نزّل نسخة احتياطية من صفحة الإعدادات بشكل دوري (زرار "نزّل نسخة احتياطية"). الملف بيتحفظ JSON وتقدر ترجّعه في أي وقت أو على أي جهاز.

أول ما تفتح التطبيق لأول مرة بيتحط فيه **بيانات تجريبية** (٤ مرضى و٣ أطباء ومواعيد) عشان تشوف شكله. امسحها كلها من الإعدادات ← "امسح كل البيانات" لما تجهز تستخدمه فعليًا.

## تصدير PDF

مفيش زرار "تصدير PDF" منفصل — بدل كده كل التقارير والروشتات والفواتير فيها زرار **طباعة**، ومن نافذة الطباعة تختار **"حفظ كـ PDF" (Save as PDF)** كطابعة.

الطريقة دي مقصودة: مكتبات الـ PDF الجاهزة بتتعامل مع العربي والكتابة من اليمين لليسار بشكل سيء (حروف مقطّعة ومقلوبة)، بينما المتصفح بيرسم العربي صح ١٠٠٪.

## شكل الكود

```
clinicflow/
├── index.html          هيكل الصفحة
├── css/styles.css      التصميم (فاتح/ليلي + تنسيقات الطباعة)
└── js/
    ├── db.js           ← طبقة التخزين (IndexedDB) — الملف الوحيد اللي بيلمس الداتابيز
    ├── store.js        منطق الكيانات والعلاقات والتحقق من البيانات
    ├── ui.js           نوافذ، تنبيهات، تنسيق التواريخ والفلوس، الطباعة
    ├── app.js          التوجيه بين الصفحات
    ├── seed.js         البيانات التجريبية
    └── pages/          صفحة لكل قسم
```

## التطوير الجاي: التحويل لداتابيز حقيقية

لو احتجت أكتر من مستخدم يشتغلوا على نفس البيانات (دكتور + سكرتارية + أجهزة مختلفة)، الحل هو داتابيز على الإنترنت زي [Supabase](https://supabase.com) (باقة مجانية كفاية للبداية).

الكود متعمل مخصوص عشان ده يبقى سهل: **`js/db.js` هو الملف الوحيد اللي بيتكلم مع التخزين**. باقي المشروع كله بيستخدم الدوال اللي بيصدّرها (`all` و`get` و`put` و`remove` و`where` …). فالتحويل معناه إعادة كتابة `db.js` وحده بحيث ينادي Supabase بدل IndexedDB — من غير ما تلمس أي صفحة تانية.
